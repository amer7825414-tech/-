# Camera + Location Consent Demo + Admin

هذه نسخة مستقلة للفكرة العامة مع موافقة واضحة:
- طلب الكاميرا الأمامية أو الخلفية بعد موافقة الزائر.
- طلب الموقع بعد موافقة الزائر.
- التقاط صورة اختياري.
- زر واضح لإرسال البيانات التي اختار الزائر إرسالها.
- لوحة إدارة محمية بكلمة مرور على `/admin`.

## Render
هذا الإصدار يحتاج **Web Service** وليس Static Site.

- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variable: `ADMIN_PASSWORD` = كلمة مرور قوية تختارها أنت

بعد النشر افتح:
- الموقع: `https://YOUR-SERVICE.onrender.com/`
- لوحة الإدارة: `https://YOUR-SERVICE.onrender.com/admin`

عند فتح `/admin` سيطلب المتصفح اسم مستخدم وكلمة مرور. يمكن ترك اسم المستخدم أي قيمة، وتكون كلمة المرور هي `ADMIN_PASSWORD`.

## التخزين على Render
الملفات داخل `data/` محلية على الخدمة. في بيئات الاستضافة التي تستخدم نظام ملفات مؤقت، قد تختفي عند إعادة التشغيل أو إعادة النشر. للاحتفاظ الدائم بالصور والسجلات تحتاج تخزينًا دائمًا أو قاعدة بيانات/تخزين خارجي.
